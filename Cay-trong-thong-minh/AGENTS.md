# AGENTS.md

## Project Overview

ESP32 Arduino smart home/plant dashboard with ST7789 TFT (320x240) + XPT2046 touch + LVGL v9.4 UI.
UI generated by EEZ Studio. Three main sketches: dashboard-only, full smart home, smart plant.

This repo also functions as an **Obsidian vault** with bases, canvas diagrams, and project notes.

## Repository Structure

- `kartis_smart_home_v1-main/justDashboardWorking/` — dashboard-only sketch (no sensors, placeholder values)
- `kartis_smart_home_v1-main/version_1_Final/` — full version with DHT11, MQ135, LDR, RTC, relays
- `smartPlant/` — smart plant sketch with DHT11, soil moisture, rain sensor, relay light+pump
- `TFT_Test/` — standalone hardware test sketch (RED→GREEN→BLUE color cycle)
- `User_Setup.h` — root-level reference copy; **NOT** the file TFT_eSPI reads
- `lv_conf.h` — root-level reference copy; **NOT** the file LVGL reads
- `.obsidian/` — Obsidian vault config
- `Bases/` — Obsidian `.base` files (table/cards views) and `.canvas` files (diagrams)
- `Tasks/`, `Books/`, `Daily Notes/` — Obsidian notes with frontmatter for bases

|----------|------|-------|

| TFT DC | 16 | RX2 |
| TFT RST | 5 | D5 |
| TFT MOSI | 23 | D23 (shared with touch) |
| TFT SCLK | 18 | D18 (shared with touch) |
| TFT BL | 32 | D32 |
| Touch MISO | 19 | D19 |
| Touch CS | 21 | D21 |
| Touch T_IRQ | 33 | Interrupt for touch detection |

## TFT_eSPI User_Setup.h Requirements

These must be set correctly in the **library's** User_Setup.h:

- `#define ST7789_DRIVER` (NOT ILI9341)
- `#define TFT_WIDTH  240`
- `#define TFT_HEIGHT 320`
- `#define TFT_RGB_ORDER TFT_BGR`
- `// #define TFT_INVERSION_OFF` (comment out both inversion lines, or try ON/OFF)
- `//#define TFT_MISO 19` (comment out — ST7789 is write-only)
- `#define SPI_FREQUENCY 27000000` (40MHz causes white screen on some modules)
- `#define TFT_CS   17`
- `#define TFT_DC   16`
- `#define TFT_RST   5`
- `#define TOUCH_CS 21`

## lv_conf.h Requirements

- `#if 1` on line 15 (must be `1`, not `0`)
- Enable fonts needed by EEZ Studio UI: 10, 12, 14, 20, 22, 24, 30, 38
- `LV_COLOR_DEPTH 16`

## Arduino IDE Setup

- Board: ESP32 Dev Module
- Upload speed: 115200 (higher causes upload failures on some boards)
- Libraries to install via Library Manager:
  - **TFT_eSPI** (by Bodmer)
  - **LVGL** v9.4.x
  - **XPT2046_Touchscreen** (by Paul Stoffregen)
  - **DHT sensor library** (by Adafruit) — version_1_Final only
  - **RTClib** (by Adafruit) — version_1_Final only

## Upload Troubleshooting

- If upload fails with "chip stopped responding": hold **BOOT** button on ESP32 during "Connecting..." phase
- If screen is white after upload: check driver (ST7789 vs ILI9341), pin assignments, and SPI frequency
- If colors are wrong: toggle `TFT_RGB_ORDER` between TFT_RGB and TFT_BGR, and toggle `TFT_INVERSION_ON`/`OFF`

## Display Orientation

- `setRotation(3)` = landscape, 180° rotated (current default)
- Touch `ts.setRotation(3)` must match TFT rotation
- To flip: change both to `setRotation(1)`

## Touch Calibration (smartPlant)

XPT2046 resistive touch requires calibration per rotation. Current values for rotation 3:
```
RAW_MIN_X = 460    (left edge)
RAW_MAX_X = 3591   (right edge)
RAW_MIN_Y = 568    (top edge)
RAW_MAX_Y = 3473   (bottom edge)
INVERT_X = false
INVERT_Y = false
```

Touch improvements in `smartPlant.ino`:
- **T_IRQ (GPIO 33)**: interrupt-based detection instead of polling
- **Z_THRESHOLD = 20**: lower threshold for finger sensitivity (library default is 400)
- **Smoothing filter**: exponential moving average to reduce jitter
- **ext_click_area(15)**: expands switch touch area by 15px each side
- **Clickable disabled**: all widgets except switches have `LV_OBJ_FLAG_CLICKABLE` removed

To recalibrate: upload `kartis_smart_home_v1-main/ESP32_ILI9341_TouchCalibrationTest-LandscapeMode.ino.ino` with `setRotation(3)`.

## Temperature Arc

Arc displays temperature as a half-circle gauge:
- Range: 0-100
- Mapping: `map(temp, 0, 50, 0, 100)` — 0°C→0, 50°C→100, 26°C→52
- Background angle: 180°→0° (top half)
- Updated in `update_dashboard()` every 500ms
